# PF2e: русская локализация по терминологии PF2.ru

Готовая поставка модуля для Foundry VTT 14 и системы Pathfinder 2e 8.
Требуется модуль **Babele** 2.9.1.

Содержимое собирается автоматически из лицензированной базы переводов;
правки здесь не вносятся -- они делаются в репозитории исходников
и попадают сюда следующей публикацией.

## Установка

Скопируйте каталог в `Data/modules/pf2ru-translation` вашего Foundry
и включите модуль вместе с Babele.

## Что переведено

Переводятся названия и текст правил тех сущностей, для которых
перевод подтверждён источником. Непереведённые сущности Foundry
показывает по-английски -- это ожидаемое поведение, а не сбой.
